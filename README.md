# Medicine Recommendation System

This project is a machine learning based medicine recommendation system developed using Python and Flask. It takes symptoms entered by the user, predicts a possible disease using a trained machine learning model, and then provides related information such as disease description, precautions, medications, diet, and workout recommendations.

Note: This project is created for educational purposes. The predictions and recommendations should not be considered a substitute for professional medical advice.

## Features

- Predicts a possible disease from the symptoms entered by the user
- Provides a description of the predicted disease
- Shows possible precautions
- Provides medication information
- Gives diet recommendations
- Provides workout recommendations
- Uses a Flask web application for the user interface
- Uses a trained machine learning model for disease prediction

## How the System Works

The user first enters the symptoms through the web application.

The symptoms are processed and converted into the format required by the machine learning model.

The trained Support Vector Classifier model is then used to predict the possible disease.

After the disease is predicted, the application searches the available datasets for information related to that disease.

The final result includes the disease description, precautions, medications, diet recommendations, and workout suggestions.

## Installation

First, clone the repository and move into the project folder.

    git clone https://github.com/YOUR_USERNAME/Medicine-Recommendation-System.git

    cd Medicine-Recommendation-System

Create a virtual environment using the following command.

    python -m venv venv

On Windows, activate the virtual environment using:

    venv\Scripts\activate

Install the required Python packages.

    pip install flask numpy pandas scikit-learn openpyxl

## Running the Project

Run the Flask application using:

    python main.py

After the application starts, open the following address in a browser:

    http://127.0.0.1:5000/

## Machine Learning Model

The project contains two trained models in the model folder.

    rf.pkl
    svc.pkl

The Flask application uses the Support Vector Classifier model stored in svc.pkl for disease prediction.

The Jupyter Notebook named medical recommendation system.ipynb contains the work related to data processing and model development.

## Datasets

Training.csv contains the data used for training the disease prediction model.

Symptom-severity.csv contains information related to symptom severity.

description.csv contains descriptions of different diseases.

precautions_df.csv contains precaution information.

medications.csv contains medication recommendations.

diets.csv contains diet recommendations.

workout_df.csv contains workout recommendations.

symtoms_df.csv contains symptom-related information.

Medicine_description.xlsx contains medicine descriptions.
